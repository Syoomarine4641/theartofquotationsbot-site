名言の流儀Bot 利用規約

最終更新日：2026年6月9日

本利用規約（以下「本規約」）は、Discord 上で提供される「名言の流儀Bot」 （以下「本サービス」）の利用条件を定めるものです。本サービスを利用するすべてのユーザー （以下「ユーザー」）は、本規約に同意したものとみなされます。

第1条（本サービスの内容）

本サービスは、Discord 上で /meigen コマンド等を実行することにより、 名言風の画像を生成・送信する機能を提供します。機能の内容は、開発者の判断により 予告なく追加・変更・停止される場合があります。

第2条（禁止事項）

ユーザーは、本サービスの利用にあたり、以下の行為を行ってはなりません。

  • 法令または公序良俗に反する行為
  • 他者の権利（著作権、肖像権、プライバシー権等）を侵害する行為
  • 誹謗中傷、差別、嫌がらせ、脅迫、過度な攻撃的表現を含むコンテンツの生成・拡散
  • 政治的・宗教的な扇動、または過度な宣伝・広告目的での利用
  • Discord 利用規約・ガイドラインに違反する行為
  • 本サービスの運営を妨害する行為、または不正アクセス・改ざん・リバースエンジニアリング等
  • その他、開発者が不適切と判断する行為

第3条（生成画像の権利および利用）

本サービスにより生成された画像（以下「生成画像」）に関する権利は、特段の定めがない限り、 本サービスの開発者に帰属します。

  • ユーザーは、生成画像を非商用の範囲で自由に利用することができます。
  • 商用利用（販売、広告素材としての利用等）を希望する場合は、事前に開発者の許可を得てください。
  • 生成画像の利用に関連して第三者との間で紛争が生じた場合、ユーザー自身の責任と費用において解決するものとし、開発者は一切の責任を負いません。

第4条（サービス提供の中断・終了）

開発者は、以下のいずれかに該当する場合、ユーザーへの事前の通知なく本サービスの全部または一部の提供を 一時的に中断または終了することができます。

  • Discord API の仕様変更・障害・停止等が発生した場合
  • サーバーやネットワーク等の保守・点検・障害対応が必要な場合
  • 天災地変、停電、その他の不可抗力が発生した場合
  • 開発者の運営上、技術上の理由により中断・終了が必要と判断した場合

第5条（免責事項）

  • 本サービスは「現状有姿」で提供され、特定の目的への適合性や完全性について、いかなる保証も行いません。
  • 本サービスの利用または利用不能によりユーザーまたは第三者に生じた損害について、開発者は一切の責任を負いません。
  • ユーザー間またはユーザーと第三者との間で生じたトラブル・紛争について、開発者は関与せず、一切の責任を負いません。

第6条（規約の変更）

開発者は、必要に応じて本規約を変更することができます。変更後の規約は、本ページに掲載された時点で効力を生じるものとします。 ユーザーが変更後も本サービスを利用した場合、変更後の規約に同意したものとみなされます。

第7条（準拠法・管轄）

本規約は、日本法を準拠法とします。本サービスに関して紛争が生じた場合、開発者の所在地を管轄する裁判所を 第一審の専属的合意管轄裁判所とします。
