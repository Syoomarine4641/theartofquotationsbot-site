名言の流儀Bot プライバシーポリシー

最終更新日：2026年6月

本プライバシーポリシー（以下「本ポリシー」）は、Discord 上で提供される 「名言の流儀Bot」（以下「本サービス」）が、ユーザーに関する情報をどのように取り扱うかを定めるものです。

第1条（収集する情報）

本サービスは、以下の情報を取得・記録する場合があります。

  • Discord ユーザー ID、ユーザー名、サーバー ID 等の Discord API を通じて取得可能な情報
  • コマンド実行時のテキスト入力内容（名言本文など）
  • Bot の動作ログ（エラー情報、実行時刻、内部処理に関する技術的ログ等）

本サービスは、ユーザーの氏名・住所・電話番号など、Discord を通じて取得できない 直接的な個人情報を意図的に収集することはありません。

第2条（情報の利用目的）

取得した情報は、主に以下の目的で利用します。

  • 本サービスの提供および機能改善のため
  • 不具合・障害発生時の調査および対応のため
  • 不正利用・スパム行為等の検知および防止のため
  • 利用状況の統計的な分析（個人を特定しない形での集計）

第3条（第三者提供）

開発者は、以下の場合を除き、取得した情報を第三者に提供することはありません。

  • 法令に基づき開示が求められた場合
  • 不正アクセス・脅迫等の違法行為があり、関係機関への通報・協力が必要と判断される場合
  • ユーザー本人の同意がある場合

第4条（データの保存期間）

ログデータ等は、運用上必要な期間保存した後、開発者の判断により安全な方法で削除または匿名化します。 保存期間は、障害対応や不正利用対策の必要性に応じて変動する場合があります。

第5条（外部サービス・Discord について）

本サービスは、Discord が提供する API を利用して動作します。ユーザーは、Discord の 利用規約およびプライバシーポリシーにも従う必要があります。

本サービス自体は Cookie を使用しませんが、ユーザーが利用するクライアント環境（ブラウザ等）において、 Discord やその他のサービスが Cookie や類似技術を使用する場合があります。

第6条（情報の管理）

開発者は、取得した情報が不正アクセス、改ざん、漏えい等の被害を受けないよう、合理的な範囲で セキュリティ対策に努めます。ただし、完全な安全性を保証するものではありません。

第7条（本ポリシーの変更）

開発者は、必要に応じて本ポリシーを変更することができます。変更後の内容は、本ページに掲載された時点で 効力を生じるものとします。本サービスの継続利用により、ユーザーは変更後の本ポリシーに同意したものとみなされます。

本サービスに関するお問い合わせ：Discord 上での連絡、または開発者が別途指定する連絡手段をご利用ください。
